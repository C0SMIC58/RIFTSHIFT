FAQ

BEFORE YOU ENTER.

Is the browser build the full game?

The public tester runs the current V16 HTML build. The desktop download packages the game as an application and is the recommended way to play it outside a browser tab.

Does progression save?

Browser progress is stored locally by the browser. Clearing site data or switching browsers/devices can remove that local profile.

Can I play on mobile?

The browser build includes touch controls, responsive UI, and optional mobile aim assist. Desktop remains the most complete control experience.

Will the site stay updated?

The website package keeps a separate play/ build and root updater payload, so future releases can update the public tester and desktop updater independently.
